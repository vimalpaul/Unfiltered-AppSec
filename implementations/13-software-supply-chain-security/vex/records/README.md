# Production VEX records

No production VEX statements are currently issued from this repository.

Add only reviewed, product-specific OpenVEX v0.2.0 JSON documents here. Each statement must identify the exact product and vulnerability, include the required status and timestamp, and provide the mandatory justification or action statement for its status.

Before marking a product `not_affected`, attach evidence for the exact artifact and the selected OpenVEX justification. A scanner's failure to find a call path is not sufficient evidence. Use `under_investigation` when evidence is incomplete.

Do not put confidential internal evidence, customer names, private endpoints, secrets or non-public exploit details in this public repository. Reference controlled evidence IDs instead.
